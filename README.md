# JJTrip 中文城市旅行攻略

JJTrip 是一款可直接部署到 GitHub Pages 的纯静态城市攻略网页。页面以五彩卡通虚拟地图为核心，包含五城地点资料、地点编辑与自定义图标、城市切换、自规划路线、本地存档、手动版本及 JSON 导入导出。

在线地址：<https://chu-junjie.github.io/JJTrip/>

## 五个城市

- 香港
- 新加坡
- 深圳
- 澳门
- 吉隆坡

每个城市都有独立的 SVG 虚拟地图布局，包含水域、陆地、主要片区、绿地、道路或轨道、中文区域名称与代表性城市插画。地点以 `mapX`、`mapY` 百分比坐标定位，不依赖任何外部地图服务。

## v4 编辑体验升级

- 进入编辑模式后，地图左上方会显示快捷工具条，可直接新增地点或完成编辑。
- 新增地点采用引导式流程：先在地图选择位置，再填写名称、选择地点类型和图标。
- 支持景点、餐厅、小吃、拍照机位、公园、博物馆、购物和交通八类地点。
- 每类地点提供一组推荐 Emoji 图标；也可输入最多 2 个 Emoji 或简短文字作为自定义图标。
- 创建完成后自动打开完整编辑面板，可继续补充简介、营业时间、价格、地址、标签、图片、拍照建议和资料来源。
- 已有地点仍可随时切换类型、恢复类型默认图标或改用自定义图标。
- 编辑模式中的提示、空状态、按钮文案和移动端布局已统一润色。

## 主要交互

- 顶部只保留 JJTrip 品牌、当前城市、搜索和地点类型筛选。
- 左上角 JJTrip 标志由 HTML 与 CSS 实时绘制成立体组件，不依赖 Logo 图片。
- 点击地图标记查看中文地点详情；详情包含简介、地址、营业时间、价格、标签、多张图片和拍照机位说明。
- 多张地点照片可左右滑动、使用方向按钮或键盘方向键观看，并显示当前页数。
- 日常浏览可把地点加入或移出规划。
- 没有规划地点时，底部路线抽屉完全隐藏。
- 加入第一个地点后出现“我的规划”收起栏，可点击或向上滑动展开、向下滑动收起。
- 两个及以上规划点会在地图上绘制带方向箭头的品牌蓝卡通虚线。
- 路线导图支持横向触摸滑动，并显示交通方式、时间、距离和备注。

## 旅行搭子与设置

页面使用透明背景的立体 3D 旅行搭子；原有 JJTrip Logo 与旅行搭子素材仍保留在 `assets` 中。旅行搭子是可拖动的悬浮桌面宠物：

- 支持鼠标与手机触控拖动。
- 自动限制在可视区域内，并避开顶部栏、路线把手和详情关闭按钮。
- 松手后把位置写入本地存储，刷新后保持原位置。
- 小幅移动视为点击，点击后打开设置。
- 设置关闭后，旅行搭子继续显示。

城市切换、编辑模式、城市资料和存档入口都位于旅行搭子设置中。

## 日常浏览与编辑模式

页面刷新后始终进入“日常浏览”。日常浏览可以搜索、筛选、查看详情、加入规划、移出规划和查看路线。

需要修改地点、拖动地点、增删地点、修改城市资料、调整路线顺序、编辑交通连接、导入或恢复存档时，请在旅行搭子设置中输入密码：

```text
123456
```

该密码只用于本地防误触，不是账号或服务器身份认证。完成修改后点击“完成编辑并锁定”。

## 数据与兼容性

- 本地存储键继续使用 `jjtrip_mvp_v3`，兼容旧版本浏览器存档。
- 旧地点中的经纬度字段会保留，并在缺少虚拟地图坐标时用于生成合理的 `mapX`、`mapY`。
- 地点照片以 `images` 数组保存；旧版单张 `image` 会自动迁移为第一张照片，同时继续维护兼容别名。
- 旧手动版本和旧 JSON 备份在恢复或导入时也会执行坐标与类型迁移。
- 地点类型统一为景点、餐厅、小吃、拍照机位、公园、博物馆、购物和交通；每类都有默认图标和推荐图标列表。
- 地点的 `emoji` 字段用于保存自定义图标；留空时自动跟随地点类型默认图标。
- 自动保存、手动版本、版本恢复、JSON 导入导出、城市切换和恢复默认数据均保留。
- 恢复、导入和删除操作都需要明确确认，不会自动删除已有数据。

建议在进行大量图片上传或重大修改前先导出 JSON 备份。每个地点最多保存 12 张照片，单张原始文件不超过 15 MB；本地图片会先压缩再写入浏览器存储，容量不足时本次修改会回滚并提示用户。

## 本地打开与部署

网页没有构建步骤，也不需要后端。可直接双击 `index.html`，也可在仓库目录启动任意静态文件服务器进行测试。

所有页面启动资源都使用相对路径：

```text
./assets/...
```

因此项目可部署在 `/JJTrip/` 子路径。部署时保留 `index.html`、`README.md` 和完整 `assets` 文件夹即可。

## 测试建议

1. 清空浏览器中 `jjtrip_mvp_v3` 后刷新，确认默认显示香港且没有路线抽屉。
2. 通过旅行搭子设置依次切换五个城市，检查地图、地点和中文区域关系。
3. 搜索与筛选地点，打开详情并点击“加入规划”。
4. 展开路线抽屉，横向滑动；向下滑动收起。
5. 拖动旅行搭子后刷新，确认位置保留且没有超出屏幕。
6. 输入 `123456` 进入编辑模式，点击“新增地点”，在地图选择位置后依次测试八种地点类型。
7. 分别测试推荐图标、默认图标、自定义 Emoji 和两个中文字图标，创建后确认地图标记、详情标题和路线节点一致。
8. 为同一地点一次选择多张照片；确认详情可左右滑动并可逐张删除。
9. 测试地点拖动、路线排序和交通连接编辑；刷新后应回到日常浏览。
10. 导出 JSON，随后在编辑模式导入该文件，确认五城、地点坐标、自定义图标、照片数组、路线、交通段和版本均保留。
11. 分别以桌面和手机宽度检查新增地点弹窗、主要按钮尺寸、地图点击区域及页面横向溢出。

## 数据边界

内置内容是便于继续维护的种子资料，不是完整商户数据库。营业时间、价格、交通路线和地点状态可能变化，实际出行前请通过官方渠道复核。
