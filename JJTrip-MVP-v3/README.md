# JJTrip 城市攻略地图 MVP v3

## 本版品牌更新

- 使用用户提供的 **JJTrip 主 Logo、App 图标和旅行搭子吉祥物**。
- 主色改为品牌蓝 `#2563EB`，辅助使用橙色、浅蓝和深灰。
- 顶部不再显示独立的齿轮设置按钮和锁按钮。
- 点击右上角的 **旅行搭子吉祥物** 进入设置界面。
- 吉祥物右下角的 🔒 / 🔓 小标记仅用于显示当前锁定状态。

## 编辑锁

设置界面最上方集中显示编辑锁：

- 页面启动或刷新后默认处于锁定状态。
- 默认密码：`123456`
- 锁定时可以浏览、搜索、筛选和查看地点，但不能修改地点、路线、城市资料或存档数据。
- 解锁后，设置中会显示“完成修改并立即锁定”按钮。
- 密码锁只用于本地防误触，不是账号级安全验证。

## 打开方式

当前版本仍使用 Leaflet 和临时地图瓦片，需联网加载。

可直接双击 `index.html` 预览；更稳定的方式是在项目目录启动本地服务器：

```powershell
python -m http.server 8000
```

然后打开：

```text
http://localhost:8000
```

## 已保留功能

- 主页面一次只显示一个城市。
- 设置栏切换香港、新加坡、深圳、澳门和吉隆坡。
- 地点按景点、餐厅、小吃、拍照机位等表情图标散落在地图上。
- 解锁后自行选择地点并生成横向滑动路线导图。
- 交通段支持方式、时间、距离和备注。
- 地点搜索、类别筛选、图片上传、图片网址和来源网址。
- 本地自动保存、版本快照、JSON导入导出和恢复。

## 地图说明

本版优先完成品牌和设置交互，**尚未接入正式高德 JS API**。设置中的“高德中文地图”仍是临时瓦片方案；下一阶段可以替换为官方高德 Web 端 Key 与 `securityJsCode` 接入。

## 数据边界

内置内容是用于筛选和继续补充的 MVP 种子数据，不是完整商户数据库。营业时间、价格、交通路线和地点状态会变化，实际出行前应通过官方渠道复核。
